

## Create Trip

A trip means the child can set up a journey to a destination, including all modes of travel.

Example: going to college
The user sets the order and modes of travel.

**Example flow:**

* Uber (with cab details) → Airport
* Flight (with flight details) → Destination city
* Uber (with cab details) → Railway station
* Train (with train details) → Final destination
* Uber → Final stop

The map updates automatically.

If a flight path or train path is not available, the system shows a straight line between locations.

Example:
If the flight path from LKO to BLR is unavailable but timing data exists:

* A path is drawn from takeoff airport to landing airport
* This path can be a straight line or approximate route

## Location Sharing

The child can share their location with the parent.

* A ping is sent whenever the browser is open
* A location ping is sent every 5 minutes

---

## When Sharing Stops

* Location sharing stops
* Last known location is saved

---

## Last Location Ping

* Displays last known latitude and longitude

---

## Share via Link

* Generates a shareable link
* Anyone with the link can view the child’s location (similar to parent view)
* They **cannot**:

  * Send notifications
  * Change settings
